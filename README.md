# Universe Lab

Universe Lab — интерактивная космическая энциклопедия на русском языке. Она соединяет симуляцию орбит, каталог небесных тел и трёхмерное исследование планет.

[Открыть Universe Lab](https://patrolraven.github.io/universe-lab/)

## Разделы

- **Симуляция.** Солнечная система, двойная звезда и орбитальная песочница. Выбирайте тела на сцене или в нижней панели, меняйте ракурс и управляйте видимостью орбит, следов, подписей и свечения.
- **Библиотека.** Карточки Земли и Марса с поиском, фильтром по категориям и научными характеристиками. Из карточки можно найти тело на орбите или сразу открыть его глобус.
- **Исследователь планет.** Глобусы Земли и Марса с картами поверхности и справкой об атмосфере, внутреннем строении и истории исследований. Стрелки вращают глобус, клавиши `+` и `−` меняют масштаб. Кнопка возврата ведёт к системе или обратно к результатам поиска.

Справочные данные и ссылки на источники находятся в профилях планет. Происхождение изображений описано в [паспорте карт планет](public/planets/SOURCES.md) и [паспорте карт Земли](public/earth/SOURCES.md). Масштаб сцены адаптирован для наглядности. Симуляция не предназначена для расчёта эфемерид.

## Локальный запуск

Нужны Node.js 22, npm и браузер с WebGL 2 для трёхмерной сцены.

```bash
npm ci
npm run dev
```

Для проверок используйте `npm test` и `npm run build`. Готовая сборка находится в `dist/`. GitHub Actions проверяет и публикует изменения ветки `main` на GitHub Pages.

## Технологии

TypeScript, Three.js, WebGL 2, Vite и Vitest. Физический движок рассчитывает попарное тяготение методом Velocity Verlet. Симуляция движется автоматически. Системная настройка уменьшения движения останавливает физическое время и отключает анимацию перелётов.

## Дорожная карта

- Подключить следующие планеты к общему формату карточек и справочника.
- Расширить каталог спутниками, звёздами и малыми телами по мере появления проверенных данных и ресурсов.

Добавляйте новые элементы интерфейса и образовательные материалы на русском языке. Научные обозначения сохраняйте в общепринятой форме.
