# Universe Lab

Интерактивная 3D-лаборатория для изучения гравитации и орбитального движения. Три готовые системы показывают движение планет вокруг звезды, двойную звезду с планетой и экспериментальную систему с газовым гигантом, спутником и наклонёнными орбитами.

## Запуск

https://patrolraven.github.io/universe-lab/#display-layers

## Статическая публикация

После `npm run build` загрузите содержимое `dist/` на статический хостинг. Сборка использует относительный базовый путь и работает как в корне сайта, так и в подкаталоге, например `/universe-lab/`. Открывайте её по HTTP(S). Шрифты, иконка и JavaScript входят в сборку. Серверная маршрутизация, переменные окружения и внешние сервисы для запуска не нужны.

Для GitHub Pages выберите **Settings → Pages → Build and deployment → Source → GitHub Actions**. После этого отправка в `main` запускает workflow **Deploy Universe Lab to GitHub Pages**. Его также можно запустить вручную для `main` на вкладке **Actions**. Workflow проверяет тесты, собирает проект и публикует `dist/` как артефакт Pages. Адрес сайта появится в результате развёртывания.

## Управление

- Выберите систему и небесное тело в левом меню. Тело также можно выбрать на сцене или по его подписи.
- Вращайте камеру перетаскиванием, меняйте масштаб колёсиком, панорамируйте правой кнопкой мыши. На сенсорном экране используйте один палец для вращения и два для масштаба и панорамирования.
- **Focus camera** приближает выбранное тело и сопровождает его. Кнопка в правом верхнем углу сцены возвращает общий вид.
- Нижняя панель управляет паузой, сбросом и скоростью от 0,25× до 8×. Клавиши **Space**, **R** и **H** управляют паузой, сбросом и общим видом, когда фокус находится вне интерактивного элемента.
- Правая панель показывает физические параметры и переключает орбиты, следы движения, подписи и свечение. На узком экране ссылка **Inspect …** в сцене открывает инспектор выбранного тела, а **Focus camera** возвращает к сцене. Управление временем закреплено снизу.

## Структура

- `src/physics.ts` рассчитывает состояние тел без зависимостей от визуализации.
- `src/data.ts` задаёт начальные состояния, физические параметры и материалы.
- `src/scene.ts`, `src/sky.ts`, `src/materials.ts` отвечают за Three.js, камеру, выбор тел и процедурную графику.
- `src/clock.ts` разделяет реальное и модельное время, а `src/trajectories.ts` рассчитывает прогнозы и хранит историю отдельных тел.
- `src/ui.ts` и `src/style.css` реализуют интерфейс на HTML и CSS.
- `src/app.ts` связывает физику, сцену и интерфейс в цикле `requestAnimationFrame`.

## Planet Explorer

В Solar System выберите Землю и нажмите **Explore Earth**. Перетаскивайте сцену для вращения, используйте колесо или жест сближения пальцев для масштаба. Кнопка **Earth information** открывает справку независимо от камеры. **Escape** сначала закрывает справку, затем возвращает к симуляции. Пока дневная карта загружается, Escape отменяет вход.

Explorer использует существующий рендерер и ту же физическую Землю. Часы, пауза и скорость симуляции остаются доступны. Модельное освещение следует за Солнцем, а справка отделяет научные характеристики Земли от параметров упрощённой симуляции. Сброс и смена сценария закрывают Explorer.

После входа первой загружается дневная карта 2K. Затем подключаются нормали рельефа и ночные огни. Кнопка загрузки 4K появляется на достаточно крупных экранах с поддержкой таких текстур. Источники, кредиты, контрольные суммы и обработка собраны в [паспорте карт](public/earth/SOURCES.md).

## Расширение каталога тел

`ObjectSpec` в `src/data.ts` связывает начальные параметры симуляции, научный профиль `profile` и настройки обзорной сцены `appearance` через стабильный идентификатор тела. `Simulation` копирует только ID, массу, координаты и скорость. Инспектор объединяет данные профиля и текущее состояние выбранного объекта.

Будущий Planet Explorer сможет по тому же ID получать обзорное описание, сведения о поверхности, атмосфере и истории исследований из `profile`. Необязательная конфигурация `detail` описывает карты поверхности, высот и облаков с атрибуцией и параметрами атмосферы. Все поля подробного режима открыты для поэтапного наполнения. Текущий интерфейс показывает описание, только когда оно задано.

## Физическая модель

Единицы модели — астрономические единицы, солнечные массы и годы. Пара тел с вектором разности положений **r** создаёт ускорение **a = GM r / (|r|² + ε²)^(3/2)**. Ускорения считаются попарно с симметричным вкладом в обе стороны, с **G = 4π²** и смягчением **ε = 0,004 а.е.**. Начальные состояния приведены к барицентрической системе отсчёта.

Интегратор Velocity Verlet выполняет два полушага для скорости и один полный шаг для координат. Аккумулятор определяет, сколько тиков по **1/2048 года** выполнить в очередном кадре. Для очень близких пар тик может делиться на меньшие внутренние шаги, чтобы разрешить более быстрые изменения ускорения. При 1× за секунду активной вкладки моделируется 0,16 года. Скорость и пауза действуют с момента ввода. Скрытое время не накапливается, а при нагрузке расчёт выполняет не более 192 тиков за одно обновление.

Светлые линии показывают прогнозы из начального состояния. При загрузке сценария копия движка с теми же настройками рассчитывает один номинальный период на тело. Неизменный прогноз используется повторно. Возмущения могут размыкать прогноз, а последующие обороты могут отличаться от показанного. Цветной след каждого тела хранит до 256 точек фактического движения и продолжает их записывать при выключенном слое.

## Ограничения MVP

- Solar System использует приближённые массы и радиусы. Расстояния, начальные фазы и наклонения подобраны для визуальной читаемости. Сценарий не предназначен для сверки с эфемеридами.
- Физические радиусы выводятся в инспекторе, а видимые размеры увеличены отдельно. Модель не включает столкновения, слияния тел, релятивистские поправки и приливные эффекты. При очень тесных сближениях смягчение и конечный шаг снижают физическую точность.
- Попарные вычисления имеют сложность O(n²). Готовые системы содержат до девяти объектов. Для нового эксперимента можно добавить начальное состояние в `src/data.ts`.
