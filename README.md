# Universe Lab

Universe Lab — интерактивная космическая энциклопедия на русском языке. Она соединяет симуляцию орбит, каталог небесных тел и трёхмерное исследование планет.

[Открыть Universe Lab](https://patrolraven.github.io/universe-lab/)

## Разделы

- **Галактика.** Интерактивная карта Млечного Пути открывается при запуске. Перетаскивайте карту, чтобы вращать её, приближайте колесом или жестом из двух пальцев и перемещайте обзор правой кнопкой мыши или двумя пальцами. Выберите маркер Солнечной системы, чтобы открыть её симуляцию. «Двойная звезда» и «Песочница» доступны в списке моделей вне карты. Форма галактики и её звёздное поле построены процедурно, а положение Солнца опирается на наблюдения.

- **Симуляция.** Полноэкранный планетарий с тремя сценариями. Выбирайте тела на сцене или в нижней полосе, читайте сведения в боковой панели, меняйте ракурс и управляйте видимостью орбит, следов, подписей и свечения.
- **Библиотека.** Указатель и иллюстрированные статьи о Солнце, восьми планетах, пяти карликовых планетах, 22 естественных спутниках и восьми учебных телах. Указатель ищет по русским и английским названиям и фильтрует по типу. Для тел на сцене из статьи можно навести камеру.
- **Explorer.** Интерактивные глобусы восьми планет. Стрелки вращают глобус, клавиши `+` и `−` меняют масштаб. На сенсорном экране перетаскивайте глобус одним пальцем и меняйте масштаб двумя. Кнопка возврата ведёт к сцене или к прежней статье и выдаче поиска. Справки доступны без WebGL.

Справочные данные и ссылки на источники находятся в статьях. Для изображений энциклопедии и карт глобусов опубликованы [источники изображений объектов](public/objects/SOURCES.md), [источники карт планет](public/planets/SOURCES.md) и [источники карт Земли](public/earth/SOURCES.md). Масштаб сцены адаптирован для наглядности. Симуляция не предназначена для расчёта эфемерид.

## Звёздный атлас

Каталог добавляет 24 записи. Поиск принимает русские и международные названия. Выберите слой объектов или откройте окрестности Солнца в радиусе 30 пк. Экзопланеты на обзорной карте отмечены в положении своей звезды. Кнопка «Открыть модель» доступна для Сириуса, Проксимы Центавра и TRAPPIST-1.

Положения рассчитываются из координат ICRS и оценок расстояний. Источники и параметры приведены в статьях каталога. Периоды в статьях взяты из публикаций или каталогов. Симуляции используют опубликованные орбитальные параметры и условное начальное расположение тел, поэтому не предназначены для расчёта эфемерид.

## Локальный запуск

Нужны Node.js 22, npm и браузер с WebGL 2 для трёхмерной сцены.

```bash
npm ci
npm run dev
```

Для проверок используйте `npm test` и `npm run build`. Готовая сборка находится в `dist/`. GitHub Actions проверяет и публикует изменения ветки `main` на GitHub Pages.

## Технологии

TypeScript, Three.js, WebGL 2, Vite и Vitest. Физический движок рассчитывает попарное тяготение методом Velocity Verlet. Симуляция движется автоматически. Системная настройка уменьшения движения останавливает физическое время и отключает анимацию перелётов.

Добавляйте новые элементы интерфейса и образовательные материалы на русском языке. Научные обозначения сохраняйте в общепринятой форме.
